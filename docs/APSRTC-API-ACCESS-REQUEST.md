**CC:** Executive Director (IT), APSRTC — edenit@apsrtc.ap.gov.in; atm2comp@apsrtc.ap.gov.in  
**Subject:** Request for authorized developer/API access to APSRTC Live Track data

Respected Sir/Madam,

I am developing **APSRTC Live**, an independent passenger-facing web application intended to help travellers discover APSRTC services and access verified bus-tracking information.

I found the Vehicle Tracking System information on APSRTC's official website. I understand that bus GPS coordinates are transmitted to APSRTC's Central Data Center and that passenger tracking is made available through APSRTC's official Live Track app and web portal.

I request guidance on whether APSRTC provides an authorized third-party integration or developer API for approved passenger applications.

If such a program is available, could you please share:
1. The application/approval process and any required organization or developer documentation.
2. API documentation and sandbox/test credentials.
3. Available endpoints and permitted fields (service, route, stop, vehicle location, last-updated timestamp, ETA, service status).
4. Authentication, rate limits, security requirements and allowed usage.
5. Attribution, privacy, data-retention and commercial/non-commercial usage conditions.
6. The process for production access and technical support.

I will not access internal systems, reverse-engineer private endpoints, or display simulated vehicle positions. Live locations and arrival estimates will only be displayed after written authorization and successful validation against the approved source. Until then, the application will direct passengers to APSRTC's official Live Track service.
